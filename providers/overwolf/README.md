# Overwolf provider

Not started yet — waiting on Overwolf app whitelisting and the Riot
developer portal approval.

Once approved, this folder will contain an Overwolf app (manifest.json +
GEP event listeners) that feeds the same `core/` session manager with
automatic round number, match score, and per-round combat stats
(damage, kills, headshots) pulled from Overwolf's Game Events Provider —
no OCR, no manual hotkey needed.
